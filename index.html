🤖 Scholarship Finder
★ Featured · AI / Multi-Agent System · Aug 2026

Gaza & Palestine Scholarship Finder — AI Agent

An interactive web platform that helps Palestinian students locate fully funded scholarships and emergency academic grants — through a smart split-screen interface and an integrated, real-time AI assistant.

  • Engineered a multi-agent system led by an Orchestrator Agent, coordinating specialized experts: a Text-to-SQL DB Read Expert, a Vector Search Expert performing semantic search over 1536-dimensional embeddings, and a DB Write Expert.
  • Built a persistent, real-time AI assistant with Flask-SocketIO, powered by LLMs via the OpenRouter API (GPT-4o / Gemma) for instant scholarship matching.
  • Designed a responsive split-screen UI connecting a live scholarship directory and saved bookmarks with the AI assistant.
